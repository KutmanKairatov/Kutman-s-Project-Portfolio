README — Design Agency

1. Как запустить проект

1. Скачать и распаковать архив Design_Agency.zip.
2. Открыть папку Design_Agency в Visual Studio Code.
3. Найти файл "index.html".
4. Открыть его в браузере (Google Chrome).
5. Сайт готов к работе.

2. Структура проекта

- "index.html" — структура сайта.
- "style.css" — оформление и дизайн сайта.
- "script.js" — JavaScript-функции.
- "photo.jpg" — главное изображение.
- "project1.jpg" — изображение первого проекта.
- "project2.jpg" — изображение второго проекта.

3. Реализованные JavaScript-функции

В проекте реализованы 4 функции:

1. Смена темы — переключение между светлой и тёмной темой сайта.
2. Мобильное меню — открытие и закрытие меню на телефоне.
3. Фильтрация проектов — возможность показывать проекты по выбранной категории.
4. Проверка формы — проверка правильности заполнения контактной формы и вывод сообщения.

4. Используемые технологии

- HTML — создание структуры сайта.
- CSS — оформление и адаптация сайта.
- JavaScript — добавление интерактивных функций.

5. Результат

Создан адаптивный сайт Design Agency, который работает на компьютере и мобильных устройствах.
